# 🎨 UI/UX to Front-End Conversion

This project demonstrates the process of transforming a UI/UX design into a fully functional and responsive front-end website using HTML, CSS, and JavaScript.

## 📌 Features

- Layout designed using consistent design systems (typography, spacing, components)
- Developed using clean, semantic HTML structure
- Responsive design for mobile, tablet, and desktop
- Optimized images for faster loading
- Modern, user-friendly interface

## 🛠️ Technologies & Tools

- Figma (or Adobe XD)
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (Vanilla)
- Chrome DevTools
- VS Code
